基本概念

首先给出隐马尔可夫模型的定义：

隐马尔可夫模型:隐马尔可夫模型是关于时序的概率模型，描述由一个隐藏的马尔可夫链随机生成不可观测的随机状态序列,再由各个状态生成一个观测从而产生观测随机序列的过程。隐藏的马尔可夫链随机生成的状态序列称为状态序列；每个状态生成一个观测，而由此产生的观测的随机序列，称为观测序列，序列的每一个位置又可以看作是一个时刻。

隐马尔可夫模型的形式定义如下:设QQQ是所有可能的状态的集合,VVV是所有可能的观测的集合:

Q=(q1,q1,…,qN),V=(v1,v2,…,vM)Q = (q_1,q_1,\dots,q_N),V = (v_1,v_2,\dots,v_M) Q=(q1​,q1​,…,qN​),V=(v1​,v2​,…,vM​)

其中,NNN是可能的状态数，MMM是可能的观测数。III是长度为TTT的状态序列,OOO是对应的观测序列:

I=(i1,i2,…,iT),O=(o1,o2,…,oT)I = (i_1,i_2,\dots,i_T),O = (o_1,o_2,\dots,o_T) I=(i1​,i2​,…,iT​),O=(o1​,o2​,…,oT​)

AAA是状态转移概率矩阵:

A=[aij]N×NA = [a_{ij}]_{N \times N} A=[aij​]N×N​

其中:

aij=P(it+1=qj∣it=qi),i=1,…,N;j=1,…,Na_{ij} = P(i_{t+1} = q_j | i_t = q_i),i=1,\dots,N;j=1,\dots,N aij​=P(it+1​=qj​∣it​=qi​),i=1,…,N;j=1,…,N

指代在时刻ttt处于状态qiq_iqi​条件下,在时刻t+1t+1t+1转移到qjq_jqj​的概率，BBB是观测概率矩阵:

B=[bj(k)]N×MB = [b_j(k)]_{N\times M} B=[bj​(k)]N×M​

其中:

bj(k)=P(ot=vk∣it=qj),k=1,2,…,M;,j=1,2,…,Nb_j(k) = P(o_t = v_k|i_t = q_j),\quad k=1,2,\dots,M;\quad,j=1,2,\dots,N bj​(k)=P(ot​=vk​∣it​=qj​),k=1,2,…,M;,j=1,2,…,N

指代在时刻ttt处于状态qjq_jqj​条件下生成观测vkv_kvk​的概率。π\piπ是初始是初始状态概率向量:

π=(πi)\pi = (\pi_i) π=(πi​)

其中:

πi=P(i1=qi),i=1,2,…,N\pi_i = P(i_1 = q_i),\quad i =1,2,\dots,N πi​=P(i1​=qi​),i=1,2,…,N

指代初始时刻处于状态qiq_iqi​的概率。隐马尔可夫模型由初始状态概率向量π\piπ,状态转移概率矩阵AAA和观测概率矩阵BBB决定。π\piπ和AAA决定状态序列,BBB决定观测序列。因此，隐马尔可夫模型可以用三元符号表示:

λ=(π,A,B)\lambda = (\pi,A,B) λ=(π,A,B)

状态转移矩阵AAA与初始状态向量π\piπ确定了隐藏的马尔可夫链，生成不可观测的状态序列。观测概率矩阵BBB确定了如何从状态生成观测，与状态序列综合确定了如何产生观测序列。从定义来看，隐马尔可夫模型做了两个基本假设：

  1. 齐次马尔可夫性假设，即假设隐藏的马尔可夫链在任意时刻ttt的状态只依赖于前一时刻的状态，与其他时刻的状态及观测无关，也与ttt无关：

P(it∣it−1,ot−1,…,i1,t1)=P(it∣it−1),t=1,2,…,TP(i_t| i_{t-1},o_{t-1},\dots,i_1,t_1) = P(i_t|i_{t-1}),\quad t = 1,2,\dots,T P(it​∣it−1​,ot−1​,…,i1​,t1​)=P(it​∣it−1​),t=1,2,…,T

  1. 观测独立性假设,即假设在任意时刻的观测只依赖于该时刻的马尔可夫链的状态，与其他观测及状态无关:

P(ot∣it,it−1,ot−1,…,i1,t1)=P(ot∣it)P(o_t|i_t,i_{t-1},o_{t-1},\dots,i_1,t_1) = P(o_t|i_t) P(ot​∣it​,it−1​,ot−1​,…,i1​,t1​)=P(ot​∣it​)

隐马尔可夫模型可用于标注,这时状态对应着标记。标注问题是给定观测的序列预测其对应的标记序列。可以假设标注问题的数据是由隐马尔可夫模型生成的。这样我们可以利用隐马尔可夫模型的学习与预测算法进行标注。

观测序列的生成过程

根据隐马尔可夫模型定义,可以将一个长度为TTT的观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​)的生成过程描述如下:

输入： 隐马尔可夫模型λ=(A,B,π)\lambda = (A,B,\pi)λ=(A,B,π),观测序列长度TTT
输出： 观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​)

  1. 按照初始状态分布π\piπ产生状态i1i_1i1​
  2. 令t=1t=1t=1
  3. 按照状态iti_tit​的观测概率分布bit(k)b_{i_t}(k)bit​​(k)生成oto_tot​
  4. 按照状态iti_tit​的状态转移概率分布{ait,it+1}\{a_{i_t,i_{t+1}}\}{ait​,it+1​​}产生状态it+1i_{t+1}it+1​
  5. 令t=t+1t = t+1t=t+1,如果t<Tt<Tt<T,转步(3),否则，终止

隐马尔可夫模型的3个基本问题

隐马尔可夫模型有3个基本问题:

  • 概率计算问题,给定模型λ=(A,B,π)\lambda = (A,B,\pi)λ=(A,B,π)和观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​),计算在模型λ\lambdaλ下观测序列OOO出现的概率P(O∣λ)P(O|\lambda)P(O∣λ)
  • 学习问题，已知观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​),估计模型λ=(A,B,π)\lambda = (A,B,\pi)λ=(A,B,π)参数，使得在该模型下观测序列概率P(O∣λ)P(O|\lambda)P(O∣λ)。即用极大似然估计的方法估计参数。
  • 预测问题，也称为解码问题。已知模型λ=(A,B,π)\lambda = (A,B,\pi)λ=(A,B,π)和观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​),求对给定观测序列条件概率P(I∣O)P(I|O)P(I∣O)最大的状态序列I=(i1,i2,…,iT)I = (i_1,i_2,\dots,i_T)I=(i1​,i2​,…,iT​)。即给定观测序列，求最有可能的对应的状态序列。

概率计算算法

直接计算法

首先介绍最直观的直接计算法，给定模型和观测序列后，计算观测序列出现的概率的直接方法便是按照概率公式直接计算。通过列举所有可能的长度为TTT的状态序列，求各个状态序列III与观测序列OOO的联合概率P(I,O∣λ)P(I,O|\lambda)P(I,O∣λ),然后对所有可能的状态序列求和，得到P(O∣λ)P(O|\lambda)P(O∣λ)。

状态序列I=(i1,i2,…,iT)I = (i_1,i_2,\dots,i_T)I=(i1​,i2​,…,iT​)的概率是:

P(I∣λ)=πi1ai1i2ai2i3…aiT−1iTP(I|\lambda) = \pi_{i1}a_{i_1 i_2} a_{i_2 i_3} \dots a_{i_{T-1} i_T} P(I∣λ)=πi1​ai1​i2​​ai2​i3​​…aiT−1​iT​​

对固定的状态序列I=(i1,i2,…,iT)I = (i_1,i_2,\dots,i_T)I=(i1​,i2​,…,iT​),观测序列O=(o1,o2,…,oT)O = (o_1,o_2,\dots,o_T)O=(o1​,o2​,…,oT​)的概率是:

P(O∣I,λ)=bi1(o1)bi2(o2)…biT(oT)P(O|I,\lambda) = b_{i_1}(o_1) b_{i_2}(o_2) \dots b_{i_T}(o_T) P(O∣I,λ)=bi1​​(o1​)bi2​​(o2​)…biT​​(oT​)

OOO和III同时出现的联合概率为:

P(O,I∣λ)=P(O∣I,λ)P(I∣λ)=πi1bi1(o1)ai1i2bi2(o2)…aiT−1iTbiT(oT)\begin{aligned} P(O,I|\lambda) &= P(O|I,\lambda) P(I|\lambda) \\\\ &= \pi_{i_1}b_{i_1}(o_1) a_{i_1 i_2} b_{i_2}(o_2) \dots a_{i_{T-1}i_T} b_{i_T}(o_T) \end{aligned} P(O,I∣λ)​=P(O∣I,λ)P(I∣λ)=πi1​​bi1​​(o1​)ai1​i2​​bi2​​(o2​)…aiT−1​iT​​biT​​(oT​)​

然后，对所有可能的状态序列III求和，得到观测序列OOO的概率P(O∣λ)P(O|\lambda)P(O∣λ)，即:

P(O,I∣λ)=∑IP(O∣I,λ)P(I∣λ)=∑i1,i2,…,iTπi1bi1(o1)ai1i2bi2(o2)…aiT−1iTbiT(oT)\begin{aligned} P(O,I|\lambda) &= \sum_{I} P(O|I,\lambda) P(I|\lambda) \\\\ &= \sum_{i_1,i_2,\dots,i_T} \pi_{i_1}b_{i_1}(o_1) a_{i_1 i_2} b_{i_2}(o_2) \dots a_{i_{T-1}i_T} b_{i_T}(o_T) \end{aligned} P(O,I∣λ)​=I∑​P(O∣I,λ)P(I∣λ)=i1​,i2​,…,iT​∑​πi1​​bi1​​(o1​)ai1​i2​​bi2​​(o2​)…aiT−1​iT​​biT​​(oT​)​

这种直接计算的复杂度是O(TNT)O(TN^T)O(TNT),在实际中并不可行。

前向算法

首先定义前向概率：

前向概率:给定隐马尔可夫模型λ\lambdaλ,定义到时刻ttt部分观测序列为o1,o2,…,oto_1,o_2,\dots,o_to1​,o2​,…,ot​且状态为qiq_iqi​的概率为前向概率，记做：

αt(i)=P(o1,o2,…,ot,it=qi∣λ)\alpha_t(i) = P(o_1,o_2,\dots,o_t,i_t = q_i|\lambda) αt​(i)=P(o1​,o2​,…,ot​,it​=qi​∣λ)

由此便可以递推求得前向概率αt(i)\alpha_t(i)αt​(i)和观测序列概率P(O∣λ)P(O|\lambda)P(O∣λ)

观测序列概率的前向算法
输入：隐马尔可夫模型λ\lambdaλ,观测序列OOO
输出: 观测序列概率P(O∣λ)P(O|\lambda)P(O∣λ)

  • 初值：

α1(i)=πibi(o1),i=1,2,…,N\alpha_1(i) = \pi_i b_i(o_1),\quad i = 1,2,\dots, N α1​(i)=πi​bi​(o1​),i=1,2,…,N

  • 递推：对t=1,2,…,T−1t=1,2,\dots,T-1t=1,2,…,T−1

αt+1(i)=[∑j=1Nαt(j)aji]bi(ot+1),i=1,2,…,N\alpha_{t+1}(i) = [\sum_{j=1}^N \alpha_t(j) a_{ji}] b_i(o_{t+1}),\quad i= 1,2,\dots,N αt+1​(i)=[j=1∑N​αt​(j)aji​]bi​(ot+1​),i=1,2,…,N

  • 终止:

P(O∣λ)=∑i=1NαT(i)P(O|\lambda) = \sum_{i=1}^N \alpha_T(i) P(O∣λ)=i=1∑N​αT​(i)

前向算法实际上是基于“状态序列的路径结构”递推计算P(O∣λ)P(O|\lambda)P(O∣λ)的算法。前向算法高效的关键在于其局部计算前向概率，然后利用路径结构将前向概率递推到全局,得到P(O∣λ)P(O|\lambda)P(O∣λ)。

后向算法

首先给出后向概率的定义:

后向概率：给定隐马尔可夫模型Λ\LambdaΛ,定义在时刻ttt状态为qiq_iqi​的条件下，从t+1t+1t+1到TTT的部分观测序列为ot+1,ot+2,…,oTo_{t+1},o_{t+2},\dots,o_Tot+1​,ot+2​,…,oT​的概率为后向概率，记做：

βt(i)=P(ot+1,ot+2,…,oT∣it=qi,λ)\beta_t(i) = P(o_{t+1},o_{t+2},\dots,o_T|i_t = q_i,\lambda) βt​(i)=P(ot+1​,ot+2​,…,oT​∣it​=qi​,λ)

与前向概率计算类似,后向概率的计算也可以采用递推算法:

观测序列概率的后向算法
输入：隐马尔可夫模型λ\lambdaλ,观测序列OOO
输出：观测序列概率P(O∣λ)P(O|\lambda)P(O∣λ)

  • 初始化:

βT(i)=1,i=1,2,…,N\beta_T(i) = 1,\quad i =1,2,\dots,N βT​(i)=1,i=1,2,…,N

  • 对t=T−1,T−2,…,1t = T-1,T-2,\dots,1t=T−1,T−2,…,1

βt(i)=∑j=1Naijbj(ot+1)βt+1(j),i=1,2,…,N\beta_t(i) = \sum_{j=1}^N a_{ij} b_j(o_{t+1})\beta_{t+1}(j), \quad i=1,2,\dots,N βt​(i)=j=1∑N​aij​bj​(ot+1​)βt+1​(j),i=1,2,…,N

  • 终止：

P(O∣λ)=∑i=1Nπibi(o1)β1(i)P(O|\lambda) = \sum_{i=1}^N \pi_i b_i(o_1)\beta_1(i) P(O∣λ)=i=1∑N​πi​bi​(o1​)β1​(i)

利用前向概率与后向概率的定义可以将观测序列概率统一写成:

P(O∣λ)=∑i=1Nαt(i)βt(i)=∑i=1N∑j=1Nαt(i)aijbj(ot+1)βt+1(j)P(O|\lambda) =\sum_{i=1}^N \alpha_t(i) \beta_t(i) =\sum_{i=1}^N \sum_{j=1}^N \alpha_t(i) a_{ij} b_j(o_{t+1}) \beta_{t+1}(j) P(O∣λ)=i=1∑N​αt​(i)βt​(i)=i=1∑N​j=1∑N​αt​(i)aij​bj​(ot+1​)βt+1​(j)

该联合概率公式告诉我们，若我们知道了某一个时刻所有状态下的前向概率，同时知道下一个时刻所有状态下的后向概率，则可以直接计算出观测序列概率。前面介绍的三个计算观测序列概率的公式实际上为我们提供了三种递推思路:

  • 前向概率递推，即从前向后递推
  • 后向概率递推，即从后向前递推
  • 前向后向概率递推，即从两个方向开始递推

这三种方法的计算复杂度均为O(TN2)O(TN^2)O(TN2)级别，对比直接计算的O(TNT)O(TN^T)O(TNT)级别，计算复杂度大大降低。

一些概率与期望值的计算

利用前向概率和后向概率，可以得到关于单个状态和两个状态概率的计算公式。

  1. 给定模型λ\lambdaλ和观测OOO,在时刻ttt处于状态qiq_iqi​的概率,记：

γt(i)=P(it=qi∣O,λ)\gamma_t(i) = P(i_t = q_i|O,\lambda) γt​(i)=P(it​=qi​∣O,λ)

γt(i)=P(it=qi∣O,λ)=P(it=qi,O∣λ)P(O∣λ)\gamma_t(i) = P(i_t = q_i|O,\lambda) = \frac{P(i_t = q_i,O|\lambda)}{P(O|\lambda)} γt​(i)=P(it​=qi​∣O,λ)=P(O∣λ)P(it​=qi​,O∣λ)​

  1. 给定模型λ\lambdaλ和观测OOO,在时刻ttt处于状态qiq_iqi​且在时刻t+1t+1t+1处于状态qjq_jqj​的概率为：

ξt(i,j)=P(it=qi,it+1=qj∣O,λ)\xi_t(i,j) = P(i_t = q_i, i_{t+1} = q_j | O,\lambda) ξt​(i,j)=P(it​=qi​,it+1​=qj​∣O,λ)

由贝叶斯公式可得：

ξt(i,j)=P(it=qi,it+1=qj,O∣λ)P(O∣λ)=P(it=qi,it+1=qj,O∣λ)∑i=1N∑j=1NP(it=qi,it+1=qj,O∣λ)\begin{aligned} \xi_t(i,j) &= \frac{P(i_t = q_i,i_{t+1} = q_j, O|\lambda)}{P(O|\lambda)} \\\\ &= \frac{P(i_t = q_i,i_{t+1} = q_j, O|\lambda)}{\sum_{i=1}^N \sum_{j=1}^N P(i_t = q_i,i_{t+1} = q_j, O|\lambda)} \end{aligned} ξt​(i,j)​=P(O∣λ)P(it​=qi​,it+1​=qj​,O∣λ)​=∑i=1N​∑j=1N​P(it​=qi​,it+1​=qj​,O∣λ)P(it​=qi​,it+1​=qj​,O∣λ)​​

公式中P(it=qi,it+1=qj,O∣λ)P(i_t = q_i,i_{t+1} = q_j, O|\lambda)P(it​=qi​,it+1​=qj​,O∣λ)计算公式为:

P(it=qi,it+1=qj,O∣λ)=αt(i)aijbj(ot+1)βt+1(j)P(i_t = q_i,i_{t+1} = q_j, O|\lambda) = \alpha_t(i) a_{ij} b_j (o_{t+1}) \beta_{t+1}(j) P(it​=qi​,it+1​=qj​,O∣λ)=αt​(i)aij​bj​(ot+1​)βt+1​(j)

  1. 将γt(i)\gamma_t(i)γt​(i)和ξt(i,j)\xi_t(i,j)ξt​(i,j)对各个时刻ttt求和，可以得到一些期望值：
  • 在观测OOO下状态iii出现的期望值：

∑t=1Tγt(i)\sum_{t=1}^T \gamma_t(i) t=1∑T​γt​(i)

  • 在观测OOO下由状态iii转移的期望值:

∑t=1T−1γt(i)\sum_{t=1}^{T-1} \gamma_t(i) t=1∑T−1​γt​(i)

  • 在观测OOO下由状态iii转移到状态jjj的期望值：

学习算法

隐马尔可夫的学习算法可以根据数据类型分为两种：

  • 训练数据包含观测序列和状态序列, 此时可采用监督学习算法
  • 训练数据仅有观测序列，此时需采用无监督学习算法

监督学习方法

假设已给训练数据包含sss个长度相同的观测序列和对应的状态序列{(O1,I1),…,(OS,IS)}\{ (O_1,I_1),\dots, (O_S,I_S)\}{(O1​,I1​),…,(OS​,IS​)},那么可以直接采用极大似然法来估计马尔可夫参数,具体方法如下:

  1. 转移概率aija_{ij}aij​的估计：设样本中时刻ttt处于状态iii,而时刻t+1t+1t+1处于状态jjj出现
    的频数为AijA_{ij}Aij​,那么状态转移概率aija_{ij}aij​的估计为：

a^ij=Aij∑j=1NAij\hat{a}_{ij} = \frac{A_{ij} }{\sum_{j=1}^N A_{ij} } a^ij​=∑j=1N​Aij​Aij​​

这其实就是一个伯努利分布的最大似然估计问题，计算比较简单。

  1. 观测概率bj(k)b_j(k)bj​(k)的估计,设样本中状态为jjj并且观测为kkk的频数是BjkB_{jk}Bjk​,那么状态为jjj观测为kkk的估计是：

b^j(k)=Bjk∑k=1MBjk\hat{b}_j(k) = \frac{B_{jk}}{\sum_{k=1}^M B_{jk}} b^j​(k)=∑k=1M​Bjk​Bjk​​

  1. 初始状态概率πi\pi_iπi​的极大似然估计为SSS个样本中初始状态为qiq_iqi​的频率

假设训练数据只包含SSS个长度为TTT的观测序列{O1,O2,…,OS}\{ O_1,O_2,\dots, O_S\}{O1​,O2​,…,OS​}
而没有相应的状态序列，学习的目标是学习隐马尔可夫模型的参数。我们将观测序列

预测算法

下面介绍两种隐马尔可夫模型的预测算法：近似算法与维特比算法。

近似算法

近似算法的想法是，在每个时刻ttt选择在该时刻最有可能出现的状态it∗i_t^*it∗​,从而
得到一个状态序列I∗=(i1∗,i2∗,…,iT∗)I^\ast = (i_1^\ast,i_2^\ast,\dots,i_T^\ast)I∗=(i1∗​,i2∗​,…,iT∗​),将该序列作为预测的结果。
给定隐马尔可夫模型λ\lambdaλ和观测序列OOO,在时刻ttt处于状态qiq_iqi​的概率
γt(i)\gamma_t(i)γt​(i)是：

γt(i)=αt(i)βt(i)P(O∣λ)=αt(i)βt(i)∑j=1Nαt(j)βt(j)\gamma_t(i) = \frac{\alpha_t(i)\beta_t(i)}{P(O|\lambda)} = \frac{\alpha_t(i)\beta_t(i)}{\sum_{j=1}^N \alpha_t(j)\beta_t(j)} γt​(i)=P(O∣λ)αt​(i)βt​(i)​=∑j=1N​αt​(j)βt​(j)αt​(i)βt​(i)​

在每一时刻ttt最有可能的状态it∗i_t^*it∗​是:

it∗=argmax1≤i≤N[γt(i)],t=1,2,…,Ti_t^* = argmax_{1 \leq i \leq N} [\gamma_t(i)],\quad t = 1,2,\dots,T it∗​=argmax1≤i≤N​[γt​(i)],t=1,2,…,T

进而得到状态序列

I∗=(i1∗,i2∗,…,iT∗)I^* = (i_1^*,i_2^*,\dots,i_T^*) I∗=(i1∗​,i2∗​,…,iT∗​)

近似算法优点是计算简单，其缺点是不能够保证预测的序列整体是最有可能的状态序列，这是因为预测的状态序列可能有实际不发生的部分。

维特比算法实际上是用动态规划来解隐马尔可夫模型的预测问题，即用动态规划来求概率最大路径(最优路径)。这时一条路径对应着一个最优序列。
