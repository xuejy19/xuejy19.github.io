概率分布中的距离度量

KL散度，JS散度，推土机距离

更新日期:   2022-08-20

在kkk近邻章节中，我总结了在样本空间中常用的两种距离度量:LpL_pLp​距离以及马氏距离。但在一些机器学习任务中，我们期望能够得到一个分布与目标分布尽可能接近，这也就引出了一个新的问题:

如何度量两个概率分布之间的距离(差异程度)？

本文将介绍一些常见的概率分布之间的距离度量，按照以下结构组织:

  • 信息量与熵
  • KL散度(相对熵)
  • 交叉熵
  • JS散度
  • 推土机理论与Wasserstein距离

信息量与熵

信息量

任何事件都会承载着一定的信息量，包括已经发生的事件和未发生的事件，只是它们承载的信息量有所不同：

🌰：对于两个事件：昨天下雨与明天下雨。昨天下雨这个事件，因为已经发生，既定事实，那么它的信息量就为0；而对于明天会下雨这个事件，因为未有发生，那么该事件的信息量就大。

从上面栗子可以看出信息量是一个与事件发生概率相关的概念，而且可以得出，事件发生的概率越小，其信息量越大。这也很好理解，因为所谓的“搞个大新闻”,也就是发生了不太可能发生的事情，"大新闻"则意味着该事件蕴含着更多的信息。从这个角度出发， 定义信息量:

信息量: 假设XXX是一个离散型随机变量，其取值集合为X\mathcal{X}X，其概率分布为:

p(x)=P(X=x),x∈X p(x) = P(X = x), x \in \mathcal{X} p(x)=P(X=x),x∈X

则定义事件X=x0X = x_0X=x0​的信息量为:

I(x0)=−log⁡(p(x0)) I(x_0) = -\log(p(x_0)) I(x0​)=−log(p(x0​))

熵

首先给出熵的定义：

在信息论与概率统计中，熵是表示随机变量不确定性的度量，设XXX是一个取有限个值的离散随机变量，其概率分布为:

P(X=xi)=pi,i=1,2,…,n P(X = x_i) = p_i, \quad i =1,2,\dots,n P(X=xi​)=pi​,i=1,2,…,n

则随机变量XXX的熵定义为:

H(X)=−∑i=1npilog⁡pi H(X) = - \sum_{i=1}^n p_i \log p_i H(X)=−i=1∑n​pi​logpi​

有了信息量的定义后，再看关于熵的定义式可以看出，熵不过是在概率分布PPP下对信息量求的期望，所以说熵实际上就是事件信息量的期望。
若pi=0p_i = 0pi​=0,则定义0log⁡0=00\log 0 =00log0=0,式中的对数一般取以2为底或者以eee为底，这时熵的单位被称作比特或纳特，由定义可知，熵只依赖于XXX的分布，而与XXX的取值无关，因此也可将XXX的熵记作H(p)H(p)H(p),熵越大，随机变量的不确定性越大。因为pi≤0p_i \leq 0pi​≤0,由H(p)H(p)H(p)函数性质(凹函数，应用拉格朗日乘子法可求最大值)可知:

0≤H(p)≤log⁡n 0 \leq H(p) \leq \log n 0≤H(p)≤logn

KL散度(相对熵)

KL散度又称相对熵，如果我们对同一个随机变量有两个独立的概率分布P(x)P(x)P(x)和Q(x)Q(x)Q(x)，我们可以使用KL散度来衡量这两个分布的差异,下面给出KL散度的定义式:

在机器学习中，PPP往往用来表示样本的真实分布，QQQ用来表示模型所预测的分布，那么KLKLKL散度就可以计算两个分布之间的差异，也就是Loss损失值:

DKL(P∣∣Q)=−∑i=1np(xi)log⁡(q(xi)p(xi))=−∑i=1np(xi)log⁡(q(xi))−(−∑i=1np(xi)log⁡p(xi)) \begin{aligned} D_{KL}(P||Q) &= -\sum_{i=1}^n p(x_i) \log(\frac{q(x_i)}{p(x_i)}) \\ &= -\sum_{i=1}^n p(x_i) \log(q(x_i)) - (-\sum_{i=1}^n p(x_i) \log p(x_i)) \end{aligned} DKL​(P∣∣Q)​=−i=1∑n​p(xi​)log(p(xi​)q(xi​)​)=−i=1∑n​p(xi​)log(q(xi​))−(−i=1∑n​p(xi​)logp(xi​))​

由于−log⁡x-\log x−logx为凸函数，由凸函数性质可知:

−∑i=1np(xi)log⁡(q(xi)p(xi))≥log⁡∑i=1nq(xi)=0 -\sum_{i=1}^n p(x_i) \log(\frac{q(x_i)}{p(x_i)}) \geq \log \sum_{i=1}^n q(x_i) = 0 −i=1∑n​p(xi​)log(p(xi​)q(xi​)​)≥logi=1∑n​q(xi​)=0

这说明KL散度具有非负的性质，这也说明P(x)P(x)P(x)与其他分布的交叉熵恒大于熵。

这里需要说明的是，虽然KL散度具有非负性，但其并不满足度量的另外两个性质:

  • 对称性
  • 三角不等式

交叉熵

KL散度由两部分组成，第一部分是交叉熵，第二部分则是P(x)P(x)P(x)的熵，P(x)P(x)P(x)因为是真实的分布，所以其熵为固定值。在机器学习任务中，我们需要评估样本固有label与我们算法的预测predictpredictpredict之间的差距，在优化过程中，我们只需关注交叉熵，所以在分类任务中，往往采用交叉熵作为loss函数。

JS散度

JS散度只是KL散度的变形，其解决了KL散度的非对称问题，其表达式如下:

JS(P∣∣Q)=12KL(P(x)∣∣P(x)+Q(x)2)+12KL(Q(x)∣∣P(x)+Q(x)2) JS(P||Q) = \frac{1}{2} KL(P(x)||\frac{P(x) + Q(x)}{2}) + \frac{1}{2}KL(Q(x)||\frac{P(x)+ Q(x)}{2}) JS(P∣∣Q)=21​KL(P(x)∣∣2P(x)+Q(x)​)+21​KL(Q(x)∣∣2P(x)+Q(x)​)

若log⁡\loglog以2为底，则JS散度的范围为[0,1][0,1][0,1],若log⁡\loglog以eee为底，则JS散度范围为[0,ln⁡2][0,\ln 2][0,ln2]。当两个分布完全相同时取下界，当两个分布完全不同时取上界。
这也就带来了一个问题，若优化时两个分布完全没有交集时,JS散度就是一个常数(111或ln⁡2\ln 2ln2),此时会出现梯度消失问题，导致无法进行优化。

Wasserstein距离

首先说明下KL散度与JS散度存在的问题:

若两个分布P,QP,QP,Q完全没有重叠，则会导致KL散度无意义(log⁡0\log 0log0),而JS散度是一个常数，也就是说出现了梯度消失问题。

而Wasserstein距离可以一定程度上解决该问题。

思想

对于两个分布PPP和QQQ，考虑从将一个分布转换成另一个分布所需的代价入手来定义概率分布的差异。下面以一个栗子来说明该距离的思想:

🌰: 考虑两个离散分布PPP和QQQ:

P1=3,P2=2,P3=1,P4=4Q1=1,Q2=2,Q3=4,Q4=3 \begin{aligned} P_1 &= 3, P_2 = 2, P_3 = 1, P_4 = 4 \\ Q_1 &= 1, Q_2 = 2, Q_3 = 4, Q_4 = 3 \end{aligned} P1​Q1​​=3,P2​=2,P3​=1,P4​=4=1,Q2​=2,Q3​=4,Q4​=3​

下面讨论应该如何"移土"，才能够使得两个分布相同:

  • 为了让P1P_1P1​与Q1Q_1Q1​相同，我们需要把P1P_1P1​的3分2到P2P_2P2​去，这样P1P_1P1​和Q1Q_1Q1​都等于1，此时P2P_2P2​等于4
  • 同理，为了让P2P_2P2​和Q2Q_2Q2​相同，需要将P2P_2P2​的土填到P3P_3P3​时，这一步将从P2P_2P2​挖2分土填到P3P_3P3​
  • 为了让P3,Q3P_3,Q_3P3​,Q3​相等，最后一步需要将Q3Q_3Q3​的1分土挖给Q4Q_4Q4​
    每一步的代价计算公式为δi+1=δi+Pi−Qi\delta_{i+1} = \delta_i + P_i - Q_iδi+1​=δi​+Pi​−Qi​,由此可得:

δ0=0δ1=0+3−1=2δ2=2+2−2=2δ3=2+1−4=−1δ4=−1+4−3=0 \begin{aligned} \delta_0 &= 0 \\ \delta_1 &= 0 +3 -1 = 2 \\ \delta_2 &= 2 + 2 - 2 = 2 \\ \delta_3 &= 2 + 1 -4 = -1 \\ \delta_4 &= -1 + 4 - 3 = 0 \end{aligned} δ0​δ1​δ2​δ3​δ4​​=0=0+3−1=2=2+2−2=2=2+1−4=−1=−1+4−3=0​

所以最终的总代价，也就是Wasserstein距离为W=∑∣δi∣=5W = \sum |\delta_i| = 5W=∑∣δi​∣=5。该栗子可以形象的用下图表示:

公式

从上面的离散栗子了解了Wasserstein距离的思想之后，下面给出一般连续分布Wasserstein距离计算公式:

W(pr,pg)=inf⁡γ∈∏(pr,pg)E(x,y)∼γ[∣∣x−y∣∣] W(p_r,p_g) = \inf_{\gamma \in \prod(p_r,p_g)} \quad E_{(x,y)\sim \gamma}[||x-y||] W(pr​,pg​)=γ∈∏(pr​,pg​)inf​E(x,y)∼γ​[∣∣x−y∣∣]

公式中∏(pr,pg)\prod(p_r,p_g)∏(pr​,pg​)指代prp_rpr​和pgp_gpg​所有可能的联合概率分布γ(x,y)\gamma(x,y)γ(x,y),直观上来说，γ(x,y)\gamma(x,y)γ(x,y)表示将分布prp_rpr​转化成pgp_gpg​所需要多少“土”，Wasserstein指代花费最少的运输方案。

Wasserstein相对于传统的KL散度和JS散而言，当两个分布具有完全不同的支撑集合时，KL散度会是无穷，JS散度会是一个常值，而W距离此时仍能反映两个分布的远近。下面以一个栗子来说明Wasserstein距离的优势所在:

🌰: 变量Z∼U[0,1]Z \sim U[0,1]Z∼U[0,1],下面给出两个分布:

P0(x1),x1=(0,Z)∈R2P1(x2),x2=(θ,z)∈R2 \begin{aligned} &P_0 (x_1), \quad x_1 = (0,Z) \in R^2 \\ & P_1(x_2), \quad x_2 = (\theta,z) \in R^2 \end{aligned} ​P0​(x1​),x1​=(0,Z)∈R2P1​(x2​),x2​=(θ,z)∈R2​

对于这个简单的栗子，不同概率密度距离度量得到的数值如下:

W(P0,P1)=∣θ∣JS(P0,P1)={log⁡2ifθ≠00ifθ=0KL(P0∣∣P1)={+∞ifθ≠00ifθ=0 \begin{aligned} W(P_0,P_1) &= |\theta| \\ JS(P_0,P_1) &= \begin{cases} \log 2 & if \theta \neq 0 \\ 0 & if \theta = 0 \end{cases} \\ KL(P_0||P_1) &= \begin{cases} +\infty & if \theta \neq 0 \\ 0 & if \theta = 0 \end{cases} \end{aligned} W(P0​,P1​)JS(P0​,P1​)KL(P0​∣∣P1​)​=∣θ∣={log20​ifθ=0ifθ=0​={+∞0​ifθ=0ifθ=0​​

在Wasserstein度量下，随着θt→0\theta_t \rightarrow 0θt​→0,概率分布序列(Pθt)t∈N(P_{\theta_t})_{t \in N}(Pθt​​)t∈N​ 收敛到P0P_0P0​,但在其他度量下并不能收敛，W距离与JS散度在该问题中对比如下图所示:

尽管Wasserstein度量具有很多优点，但其缺点也十分明显：

计算非常复杂，优化问题不易解

目前能够显示计算出Wasserstein的只有两种情况：

高斯分布

对于两个离散的一维概率分布，可以直接使用scipy.stats.Wasserstein_distance函数:

import numpy as np
from scipy.stats import wasserstein_distance
p = [0,5,9]
q = [2,5,7]
w = wasserstein_distance(q,p)
print(w)
