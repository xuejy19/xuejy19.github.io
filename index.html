我主要从事 Agentic RL Infra 研发。在华为 2012 实验室，我参与了 Agent 训练框架、分布式经验数据引擎与沙箱执行系统的设计和开发，围绕多轮工具交互、轨迹构建、异步数据流转与大规模 rollout，解决训练过程中的正确性、效率和稳定性问题。

未来，我希望进一步深入训练与推理引擎，围绕长程 Agent 任务探索算法、模型与系统的协同设计。我关心如何在模型效果、训练效率与计算成本之间做出更好的权衡，让智能体能够在更复杂的真实环境中学习和改进。
